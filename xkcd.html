How it works

The official xkcd archive has every comic title and link. This page fetches that archive and caches it in your browser. Because some hosts block cross-site fetches, it tries several readable mirrors/proxies. If all live loading fails, it still has a small emergency index. Context search is local and private; only archive loading and the optional Google links touch the network.
