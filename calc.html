    Calculator controls & keyboard shortcuts

    Start with numbers, trigonometry, logarithms, powers and factorials; ENTER calculates and Ans reuses the last answer. CALC returns here from graphing. Use Y= to edit up to eight functions, WINDOW to set axis ranges, ZOOM for presets, TRACE to follow a curve, and GRAPH to plot. MODE changes radians/degrees and parameter a. MATH inserts more functions. TABLE shows function values.

    The control pad navigates the open menu. In Y=, up/down selects a function and left/right moves the text cursor. On the graph, arrows pan. In TRACE, left/right steps along the selected curve and up/down switches curves. OK and ENTER select. CLEAR clears the active expression or closes a menu. Escape or CALC returns to calculation. Press 2nd then GRAPH for the table, or 2nd then a trig/log key for its alternate function.

    Type expressions such as x^2 − 4, sin(x), sqrt(x) or 2x + 1, or use the keypad. Curves update as you edit. Tap the coloured Y label to hide or show a curve. Drag to pan, scroll or pinch to zoom. Use +/− while the graph is focused to zoom, and 0 to reset. An exact x value can be entered below the calculator.

    Calculation history, graph expressions, angle mode, parameter and window are saved in this browser. Use the resize handle to adjust the calculator on the page. The pop-out shows only the calculator and scales as the window is resized. Graphs show real values; gaps appear where a function is undefined. Very rapid oscillations may need a closer zoom. Save PNG is in MODE.
