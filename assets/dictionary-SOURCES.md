# Dictionary & Thesaurus

- Definitions and word relations come from the English Wiktionary Action API, scoped to the selected modern language. French, Norwegian and German definitions are English glosses; synonyms remain in the selected language.
- Norwegian synonyms and antonyms are supplemented by Norwegian Wiktionary, restricted to its Norsk sections. No translation lists are treated as synonyms.
- Wiktionary text is adapted under CC BY-SA 4.0. Each entry links its source, any linked full entry, supplemental Norwegian source and the licence.
- English synonyms fall back to Datamuse's `rel_syn` endpoint when Wiktionary lists none. Attribution appears when used.
- British English is the initial default. UK usage senses are prioritised; common US spelling variants in English display text and synonyms are adapted to British spelling. Linked source entry names remain unchanged. Device speech requests `en-GB`; other languages request `fr-FR`, `nb-NO`, and `de-DE`.
- Oxford is the first English reference and opens the Oxford Advanced Learner's Dictionary English search. On-page content is not represented as Oxford content. No Oxford subscription, credentials, scrape or licensed feed is used.
- Other reference links: Collins Thesaurus, Larousse, CNRTL, Ordbøkene, Synonymordboka, DWDS and OpenThesaurus.
- The dictionary-book SVG is original vector artwork made for Gregle.

Requests occur on explicit lookup (or a URL containing a query), not while typing. Completed entries are cached only in memory; the chosen language preference is stored locally. A 16-second deadline and cancellation prevent obsolete results replacing newer searches. Remote HTML is parsed off-screen and only extracted text is rendered.
