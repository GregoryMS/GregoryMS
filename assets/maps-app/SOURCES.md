# Gregle Maps icon

Original SVG artwork created for Gregle: a white and lavender folded map and purple location pin on the site's dark rounded tile. No third-party artwork is embedded. The icon is reused by the shared app launcher and the Maps page favicon.

The same SVG artwork is exported as `apple-touch-icon.png` (180px), `icon-192.png` (192px), `icon-512.png` (512px), and `favicon-32.png` (32px). Exports render the original SVG at 1024px on an opaque `#242424` square, then resize with Lanczos filtering. The operating system applies its own Home Screen corner shape. Maps uses its own `maps.webmanifest`, `/maps.html` launch page and Maps Home Screen label.
